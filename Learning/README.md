# Learning package

This folder turns Project 07 into a systems-design course. Read `learning-path.md`, study each concept before its implementation phase, walk the scenario files, then answer the interview set without looking at the answers.

| Concept | Reading | Phase |
|---|---|---:|
| Reproducible evaluation boundaries | `concepts/01-reproducible-evaluation.md` | 00 |
| Golden datasets and governance | `concepts/02-golden-datasets.md` | 01 |
| Metrics and failure attribution | `concepts/03-metrics-and-failure-layers.md` | 02 |
| Adapters and nondeterminism | `concepts/04-adapters-and-nondeterminism.md` | 03 |
| Runs, replay, experiments | `concepts/05-runs-replay-experiments.md` | 04 |
| LLM judges | `concepts/06-llm-judges.md` | 05 |
| Regression statistics | `concepts/07-regression-statistics.md` | 06 |
| CI gates and waivers | `concepts/08-ci-gates.md` | 07 |
| Online evaluation and privacy | `concepts/09-online-evals-and-privacy.md` | 08 |
| Structured/RAG/tool profiles | `concepts/10-extension-profiles.md` | 09 |

Learning is complete when the learner can derive a case decision, explain why a deployment stopped, distinguish deterministic evidence from judge opinion, reproduce a run from its manifest, and defend the V1 omissions.
